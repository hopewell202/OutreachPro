# OutreachPro 🚀

A professional email outreach and automation platform with follow-up sequences, contact management, and tracking.

## Features

✅ **Email Campaign Management** - Create and manage email campaigns  
✅ **Contact Database** - Upload and organize up to 30k contacts  
✅ **Follow-up Sequences** - Automated email sequences (Email 1 → wait 3 days → Email 2)  
✅ **Personalization** - Dynamic fields: {{FirstName}}, {{Company}}, {{Email}}  
✅ **Gmail Integration** - Send emails directly from your Gmail account  
✅ **Tracking** - Monitor opens, clicks, and replies  
✅ **Dashboard** - Real-time campaign analytics and statistics  

## Quick Start

### Prerequisites
- Node.js v14+
- Gmail account with API access

### Installation

```bash
git clone https://github.com/hopewell202/OutreachPro.git
cd OutreachPro
npm install
npm start
```

## Project Structure

- **Backend** - Node.js/Express API
- **Frontend** - React Dashboard  
- **Database** - SQLite/PostgreSQL

## Usage

1. Connect your Gmail account
2. Upload contacts via CSV (up to 30k)
3. Create email templates with personalization
4. Set up follow-up sequences
5. Launch campaigns and track results

## Tech Stack

- Frontend: React.js
- Backend: Node.js + Express
- Database: SQLite / PostgreSQL
- Email: Gmail API
